# Images AgriSénégal

Remplacez les fichiers suivants par vos photographies (libres de droits recommandé) :

| Fichier | Usage |
|---------|--------|
| `hero.jpg` | Bannière page d'accueil |
| `login-bg.jpg` | Arrière-plan connexion |
| `presentation.jpg` | Section présentation |
| `producer.jpg` | Section producteurs |
| `distributor.jpg` | Section distributeurs |
| `harvest.jpg` | Récoltes (optionnel) |
| `fields.jpg` | Champs (optionnel) |
| `testimonial.jpg` | Témoignages (avatar par défaut) |

**Dimensions recommandées :** 1920×1080 (hero, login), 800×600 (sections).

Tant que ces fichiers ne sont pas présents, l'application utilise des images Unsplash en secours (voir `config/agri.php`).

Les placeholders SVG sont dans `placeholders/`.
